How to use

It takes ten seconds.

  1. Look at your sensor. Did it beep?
  2. Press Yes or No at the top of the page.
  3. Do what the green card says. Water the amount it shows, or wait and check later.

Run it on your computer

You need Python 3.12 and git. Then type these three lines in a terminal and open localhost:8000.

git clone https://github.com/lordwateroff/greenhouse-ai
cd greenhouse-ai && make setup
make dev
